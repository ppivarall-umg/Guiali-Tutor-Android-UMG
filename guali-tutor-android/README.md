# Guali Tutor Android (Fase 3)

Front end visual de Guali Tutor para Android, hecho en Kotlin con vistas XML.

Incluye la barra de menú, el título de la lección activa, el panel de lección, el editor de código, los botones Compilar y Ejecutar y el panel de consola.

Esta versión es solo el front end (la parte visual): los menús y botones todavía no ejecutan acciones.

Abrir con Android Studio: File > Open y elegir esta carpeta.
